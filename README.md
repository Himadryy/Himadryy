# Hi, I'm Himadry Dey

**Backend & AI Systems Engineer** building privacy-first, high-concurrency software with Rust, Python, FastAPI, distributed systems, RAG, and local LLMs.

I like turning difficult engineering constraints into practical systems: keeping sensitive data local, making async workloads reliable, and documenting how software behaves under real conditions.

## What I build

- Privacy-first AI platforms with local inference and PII protection
- High-concurrency backend services and event-driven systems
- RAG pipelines, document intelligence, and developer tools
- Secure, reproducible deployments with Docker and CI

## Featured projects

### [DRY AI Platform](https://github.com/Himadryy/dry-ai-platform)
Air-gapped enterprise AI architecture for sensitive environments. PII is redacted before retrieval and local LLM inference through a pipeline of **Privacy Gatekeeper -> RAG Engine -> Qdrant -> Local LLM**.

**Focus:** Python, FastAPI, Haystack, Qdrant, Presidio, Docker, Ollama

### [Project Aegis](https://github.com/Himadryy/auto-mod-bot)
Rust-based Discord security and moderation system designed for high-volume event handling, Redis-backed rate limiting, and privacy-preserving local AI threat analysis.

**Focus:** Rust, Tokio, Twilight, Redis, PostgreSQL, Ollama

### [NeuroNotes AI](https://github.com/Himadryy/neuronotes-ai)
AI study assistant that turns notes and documents into summaries, quizzes, contextual chat, and visual knowledge maps using OCR, RAG, and local-first inference.

**Focus:** Python, FastAPI, Next.js, TypeScript, ReactFlow, Ollama, Gemini
